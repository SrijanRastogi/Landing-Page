# Landing Page

A landing page built as part of **The Odin Project**.

The objective of this project was to recreate a provided design using only **HTML** and **CSS**, with a strong focus on **Flexbox** for layout.

## Preview

 https://srijanrastogi.github.io/Landing-Page/

## Features

- Semantic HTML5 structure
- CSS Flexbox layout
- Responsive-style spacing for desktop layout
- Hero section with call-to-action
- Information cards
- Testimonial/Quote section
- Call-to-action banner
- Footer

## Built With

- HTML5
- CSS3
- Flexbox
